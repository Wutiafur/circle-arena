# 圆环斗场（Circle Arena）

一场快节奏、角色各异的 **自动对战竞技场**（Auto Battler Arena）。角色会在竞技场内自动移动、追击目标、触发普攻与技能，直到场上只剩下最后一方。

## 🚀 运行方式

### Windows 一键启动
双击 `LaunchGame.bat`（会自动检测 Python、缺少 pygame 时自动安装，再后台启动游戏）。

### 手动启动
```bash
pip install pygame
python main.py
```

## 📁 项目结构

```
circle/
├── main.py                 # 游戏本体（菜单/战斗/图鉴/效果图鉴/胜率统计/崩溃报告）
├── design_characters.py    # 从 sheding/charactor.md 解析设计角色的生成器
├── LaunchGame.bat          # Windows 一键启动脚本
├── itch_page.html          # itch.io 宣传页
├── win_rate_stats.json     # 各角色胜率统计（对局后自动更新）
├── sheding/
│   ├── charactor.md        # 设计角色图鉴数据（41~102 号等，改它=加角色）
│   └── 角色模板.md          # 新增角色的填写模板
├── bug/                    # 崩溃报告归档（自动生成的进 bug/crash_*.txt）
└── 预览图                 (*.png 菜单/战斗/图鉴截图)
```

## 🎮 内容概览

- **102 个角色**（40 个基础角色 + 62 个设计角色），包含四圣兽（玄武 100 / 白虎 101 / 青龙 102 / 凤凰 99）与特殊机制角色
- **自动战斗**：角色自行寻敌、普攻充能、释放技能，混战决出胜负
- **角色图鉴**：编号排序、搜索、形态展示、战绩联动（详情页显示出场/胜率）
- **效果图鉴**：负面/正面状态说明
- **战斗侧边栏**：输出/承伤排行 + 角色实时状态（凤羽、玄甲、虎魄、龙息等）
- **胜率统计**：每局结束自动记录并写入 win_rate_stats.json

## 🧭 加新角色

1. 在 `sheding/charactor.md` 末尾按 `角色模板.md` 格式添加角色块（编号+中文名+英文名）
2. 特殊技能 token 等在 `design_characters.py` 的 `ROLE_CONFIG_OVERRIDES` 中挂载
3. 复杂机制在 `main.py` 中实现对应逻辑

## ⚠️ 已知说明

- 基础角色的普攻/攻速会经 `rebalance_basic_attacks()` 网格化（普攻×0.5 取整×10、攻速统一 1.0）；给角色加 `use_design_attack_speed: True` 可保留自定义攻速。
